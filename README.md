## About the Organization

**CraftingGames** is an independent development project centered around creating custom Minecraft experiences, scalable supporting infrastructure, and specialized tools. 

What began as a standard Minecraft network has evolved into a comprehensive technical ecosystem consisting of game servers, backend services, web applications, and large-scale content projects. Rather than relying on out-of-the-box solutions, we design, build, and maintain our components internally—from server software and management systems to content creation workflows.

> [!NOTE]
> **Our Philosophy:** Build custom solutions where existing ones are limiting, create experiences that feel unique, and maintain full control over the technology that powers them.

---

## 🏗️ Core Ecosystem

While our codebases are securely maintained in private repositories, they power a highly interconnected public ecosystem. The projects below form our technical foundation.

### CraftingGames Network
The central hub and primary testing ground for our internally developed technologies. It provides players with unique multiplayer experiences built on top of Minecraft, pushing past standard gameplay to focus on custom systems, original mechanics, and long-term project development.
* **Core Focus:** Custom gameplay mechanics, scalable server infrastructure, player management systems, and cross-network services.

### CraftingGames API
The technical backbone connecting our entire infrastructure. As our ecosystem expanded, the API was developed to ensure centralized data management and seamless internal communication.

## ⚔️ Flagship Project: Faywyn

**Faywyn** is our most ambitious creative endeavor, demonstrating what can be achieved when advanced software engineering meets deep game design.

It is a large-scale fantasy roleplay and adventure world built entirely within Minecraft. Unlike traditional survival modes, Faywyn is a highly structured, persistent RPG environment.
* **Key Elements:** Story-driven gameplay, custom progression systems, deep world-building, quest mechanics, and entirely unique items, equipment, and user interfaces.

## 🛠️ Standalone Tooling: CursorCS Editor

<br>

> [!NOTE]
> *CursorCS Editor is a standalone side project. While created by members of our team, it is completely independent of the main CraftingGames ecosystem and operates with its own distinct goals.*

The **[CursorCS Editor](https://cursor-editor.craftinggames.net)** is a visual, web-based tool designed to simplify the creation of complex Minecraft GUI systems. 

It is built specifically as a configuration tool for the **CursorCS plugin** (a third-party plugin developed by Arigeta). Our web editor is officially recognized by the plugin developer as a premier workflow tool.

* **The Goal:** Replace manual configuration files with an intuitive graphical interface. Creators can design interactive layouts visually and automatically generate the required output, drastically reducing complexity and improving the developer experience.
